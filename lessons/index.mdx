## Learning with Claude Code

The repo's `CLAUDE.md` sets Claude Code up as a tutor: one concept per step, the *why* before any code, a pause after each step so you can run it, and links back to interview questions. Open a lab in Codespaces, run `claude` in the terminal, and try:

- "Walk me through the rate limiter interview design, Part 1."
- "Let's build step 1 of the rate limiter."
- "Quiz me on the load balancer cheat sheet."
- "Design a URL shortener as a new experiment, same structure as the others."

When you're done, run `/wrap-up`. Claude saves a summary of what you learned to your own notes in the repo and drafts fixes wherever these lessons fell short for you. You choose what to send, and it goes in as a pull request for review. That's how the lessons get better for the next reader.
